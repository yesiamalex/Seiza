This folder is the default world's configuration. It intentionally ships
without a `scene.glb` or any `.vrm` file.

Per `THIRD_PARTY_ASSETS.md`, third-party 3D assets are only committed when
their license clearly allows redistribution. Nothing here needs one:

- **The world isn't blank.** `src/scene/BaseEnvironment.tsx` builds two
  connected rooms entirely in code: a social hall with benches around a
  tatami platform, a reception desk, planters and paper lanterns, and —
  through a corridor of shoe lockers — a classroom with desks, a chalkboard
  and a window wall. Every chair and bench can be sat on by clicking it.
  The floor plan lives in `src/scene/layout.ts`, and the wood, tatami and
  plaster textures are drawn onto a canvas at startup, so there is still
  nothing to download or license. Set `sceneUrl` in `world.json` to any
  glTF 2.0 file to use your own space instead; if it fails to load, the app
  falls back to the built-in rooms.
- **Everyone gets a real avatar.** With `defaultAvatarUrl` empty (as here), a
  first-time visitor starts with the built-in designer's default look, and
  can pick a designer preset (businessman, businesswoman, casual, student,
  creative), customize one, or upload their own `.vrm`. Designer avatars are
  generated in code, so there is no file to license. Add your own `.vrm`
  presets through `defaultAvatars`; `THIRD_PARTY_ASSETS.md` lists CC0 sources.
  If a model ever fails to load, `VrmAvatar.tsx` shows a plain placeholder
  instead of an invisible player.
- **Gestures and locomotion are built in.** The idle, walk, run, and gesture
  clips are generated by `scripts/generate-motions.mjs`, including the held
  poses for a raised hand and for sitting. Add or replace gestures with
  `customGestures`; see `public/gestures/README.md`.

`world.json` fields:

| Field | Meaning |
|---|---|
| `id` | Room id. Must match this folder name and `VITE_SEIZA_WORLD_ID`. |
| `displayName` | Shown on the join screen and HUD. |
| `sceneUrl` | Optional glTF environment layered over the procedural room. |
| `spawnPoint` | Where players appear. |
| `defaultAvatarUrl` | A `.vrm` URL for first-time visitors, or `""` for the designer default. |
| `defaultAvatars` | Optional `.vrm` presets: `[{ "label", "url" }]`. |
| `enabledGestures` | Optional allowlist of built-in gesture names. Omit to offer all. |
| `customGestures` | Optional `.vrma` clips: `[{ "name", "label", "url", "fullBody"? }]`. |
| `maxOccupants` | Client-side hint; the server cap is `SEIZA_MAX_OCCUPANTS`. |
| `voiceEnabled` | Show voice chat controls. |
| `editingEnabled` | Allow Edit Mode. |
| `allowAvatarUpload` | Allow `.vrm` uploads. |
